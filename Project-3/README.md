# Payroll Management Calculator

This Excel project was completed as part of an Excel practice challenge.

## Project Overview
The spreadsheet was used to calculate employee payroll information using Excel formulas and structured calculations.

## Tasks Completed
- Calculated base salary using hours worked and pay rate
- Added employee bonuses
- Calculated gross pay
- Applied tax calculations
- Calculated net pay
- Computed totals for payroll data

## Skills Used
- Excel formulas
- Payroll calculations
- Cell references
- Spreadsheet organization
- Data calculations and totals

## Tools Used
- Microsoft Excel
