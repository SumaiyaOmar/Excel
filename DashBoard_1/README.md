# 📊 Dashboard Project 1 – Interactive Sales Dashboard

## 📌 Project Overview

This is a **simulated business project** created for Excel practice and portfolio demonstration.

The project simulates a retail business that needs an interactive sales dashboard to monitor its sales performance and analyze customer orders.

The dashboard was created using Microsoft Excel and is connected to product and order data within the same workbook.

---

## 🎯 Project Objective

The objective of this simulation was to transform order data into a clear and interactive business dashboard that allows a business user to:

- Monitor total sales
- Monitor total orders
- View average order value
- Compare sales across categories
- Identify top-selling products
- Filter the dashboard by category

---

## ✨ Dashboard Features

- **Total Sales KPI**
- **Total Orders KPI**
- **Average Order Value KPI**
- **Sales by Category PivotChart**
- **Top Selling Products PivotChart**
- **Interactive Category Slicer**
- PivotTables used as the foundation for the dashboard
- Professional dashboard layout and formatting
- Interactive filtering across dashboard charts

## 🧪 Testing

The dashboard was tested by adding new orders to the Orders table.

After refreshing the PivotTables, I verified that:

- Total Sales updated
- Total Orders updated
- Average Order Value updated
- PivotTables reflected the new data
- PivotCharts reflected the updated data
- Dashboard filtering continued to work correctly

This confirmed that the dashboard responds correctly when additional order data is added and the PivotTables are refreshed.
