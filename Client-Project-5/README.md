# 📊 Client Project 5 – Product Sales & Order Management System

## 📌 Project Overview

This project simulates a real client request to create an automated Product Sales & Order Management System using Microsoft Excel.

The workbook contains two connected worksheets:

- **Products** – Stores the product database.
- **Orders** – Records customer orders and automatically retrieves product information.

The goal was to reduce manual data entry, improve accuracy, and generate a sales summary for business reporting.

---

## ✨ Features

- Product database with Product ID, Name, Category, and Unit Price
- Customer order tracking
- Product ID drop-down list using Data Validation
- Automatic Product Name, Category, and Unit Price retrieval using XLOOKUP
- Automatic Total calculation (Unit Price × Quantity)
- Sales Summary using SUMIFS
- Professional table formatting
- Conditional formatting for high, medium, and low-value orders
- Dynamic workbook that automatically updates formulas and calculations when new orders are added to the table
