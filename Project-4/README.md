# Employee Timesheet and Payroll Calculator

This Excel project was completed as part of an Excel practice challenge focused on payroll calculations and spreadsheet formatting.

## Project Overview
The spreadsheet was used to manage a two-week employee timesheet and calculate payroll information automatically using Excel formulas.

## Tasks Completed
- Calculated overtime rate based on hourly pay
- Calculated regular pay and overtime pay
- Calculated total employee pay
- Added payroll totals using formulas
- Used fill handle to copy formulas and values
- Applied formatting, styles, and currency formatting
- Organized and formatted the spreadsheet professionally

## Skills Used
- Excel formulas
- Payroll calculations
- Absolute cell references
- Fill handle
- Spreadsheet formatting
- Data organization

## Tools Used
- Microsoft Excel
