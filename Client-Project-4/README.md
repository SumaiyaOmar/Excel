# Customer Invoice Tracker

## Project Overview

This project is a customer invoice tracking system created in Microsoft Excel for a fictional client. It helps businesses monitor invoices, calculate balances, track payment status, and summarize invoice data for better financial management.

---

## Features

- Recorded customer invoice information
- Calculated Net Invoice Amount
- Calculated Balance Due
- Automatically identified Invoice Status (Paid, Partial, Unpaid)
- Automatically generated Payment Remarks
- Created a summary dashboard with key business metrics
- Applied conditional formatting to highlight payment status
- Used professional table formatting and accounting number formatting

---

## Excel Skills Used

- SUM
- IF (Nested IF)
- IFS
- COUNTIF
- Basic arithmetic formulas
- Cell references
- Table formatting
- Accounting number formatting
- Conditional Formatting
- Fill Handle
- Cell alignment and formatting

---

## Summary Metrics

- Total Invoice Amount
- Total Tax
- Total Discount
- Total Paid Amount
- Total Balance Due
- Number of Paid Invoices
- Number of Partial Invoices
- Number of Unpaid Invoices
