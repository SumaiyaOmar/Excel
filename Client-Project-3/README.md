# 👨‍💼 Client Project #3 – Employee Attendance & Salary Report

## Project Overview

This project was completed as part of my Excel Freelancer Bootcamp, where I build practical business solutions by simulating real client requests.

### Client Scenario

A small business owner needed an Excel workbook to calculate employee salaries, overtime pay, and attendance performance while creating a professional payroll summary for monthly reporting.

## Objectives

- Calculate employee base salaries
- Calculate overtime pay
- Calculate total salary for each employee
- Determine attendance status based on days worked
- Create a payroll summary
- Present payroll data in a professional report

## Features

- Professional employee payroll table
- Automatic Base Salary calculation
- Automatic Overtime Pay calculation
- Total Salary calculation
- Attendance Status using Nested IF
- Payroll summary dashboard
- Conditional Formatting
- Accounting/Currency formatting
- Professional report layout

## Excel Skills Used

- SUM
- MAX
- MIN
- COUNTA
- IF
- Nested IF
- Absolute Cell References
- Basic arithmetic formulas
- Fill Handle
- Table formatting
- Conditional Formatting
- Accounting/Currency formatting
- Data organization
- Business reporting

## What I Learned

This project helped me practice building a real-world employee payroll system in Microsoft Excel. I learned how to calculate salaries using formulas, apply absolute cell references, create multiple logical conditions using Nested IF statements, summarize payroll data, and format reports professionally for business use.
