# Customer Data Cleaning & Analysis — Excel

## 📌 Project Overview

This is a **simulated client project** created to practice real-world Excel data cleaning and data management.

The project started with a dataset containing **40 customer records** that needed to be cleaned, standardized, organized, and checked for errors.

The goal was to transform the original dataset into a clean, consistent, and easy-to-use customer database and create a simple summary of the cleaned data.

---

## 🎯 Project Scenario

A client provided a customer dataset containing 40 records and requested the following:

* Clean inconsistent customer information
* Standardize names, emails, phone numbers, cities, and country values
* Identify and remove duplicate records
* Apply data validation
* Organize and format the cleaned dataset
* Calculate basic business statistics
* Create a summary of the cleaned data

## 🧹 Data Cleaning Process

The original dataset contained inconsistent formatting and duplicate information.

The cleaning process included:

1. Cleaning extra spaces from text
2. Standardizing customer names
3. Standardizing email addresses
4. Cleaning and standardizing phone numbers
5. Standardizing city names
6. Standardizing country values
7. Identifying duplicate records
8. Removing the duplicate record
9. Applying data validation
10. Sorting and organizing the cleaned dataset
11. Formatting dates and order amounts
12. Performing final quality checks

---

## 📊 Dataset Result

The original dataset contained:

**40 customer records**

After identifying and removing one duplicate record:

**39 unique customer records remained**

The original Raw Data sheet was preserved separately so that the cleaning process could be compared with the original dataset.

---

## 📈 Summary Analysis

A separate Summary sheet was created to provide basic information about the cleaned dataset, including:

* Total Customers
* Total Order Value
* Average Order Value
* Highest Order Value
* Lowest Order Value

The summary uses Excel formulas so the calculations can update when the underlying cleaned data changes.

---

## 🧪 Testing & Quality Check

The workbook was tested to make sure the formulas and data validation were working correctly.

A temporary order value was changed to test whether the Summary calculations updated correctly. The calculations updated as expected.

Data Validation was also tested by entering an invalid country value. Excel displayed the validation warning, confirming that the restriction was working correctly.
