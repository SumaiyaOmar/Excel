# Customer Churn Analysis in Excel

## Project Overview

This project is an Excel-based customer churn analysis designed to analyze customer information, identify churn patterns, and present key findings through an interactive dashboard.

The project uses a simulated customer dataset and demonstrates practical Excel skills including data organization, cleaning, formulas, conditional formatting, PivotTables, data analysis, and dashboard creation.

## Project Objectives

* Organize and clean customer data
* Analyze customer churn patterns
* Calculate key customer and churn metrics
* Compare churn rates across different customer groups
* Summarize findings using PivotTables
* Create a visual dashboard for quick analysis
* Present important business insights in an easy-to-understand format

## Dataset

The dataset contains simulated customer records with information such as:

* Customer ID
* Customer Name
* Gender
* Age
* Location
* Subscription Type
* Monthly Charges
* Tenure
* Contract Type
* Payment Method
* Support Calls
* Churn Status
* Customer Segment

### 4. Dashboard

* KPI cards

## Key Findings

Based on the simulated dataset:

* The overall customer churn rate is **40%**.
* Customers with **Monthly contracts** have the highest churn rate at **100%**.
* The **Standard subscription** has the highest churn rate among subscription types at **57%**.
* **New customers** have the highest churn rate among customer segments at **100%**.
* Female customers have a higher churn rate than male customers (**50% vs. 30%**).
