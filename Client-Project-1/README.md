# 📊 Client Project #1 – Monthly Sales Report

## Project Overview

This project was completed as part of my Excel Freelancer Bootcamp, where I simulate real client requests to build practical business solutions.

### Client Scenario

A small office supplies business needed a professional monthly sales report to organize sales data, calculate revenue, and summarize business performance.

## Objectives

- Organize monthly sales data
- Calculate total sales for each transaction
- Create a summary section
- Present the data in a clean and professional format

## Features

- Professional sales report layout
- Total Sales calculations
- Total Revenue summary
- Highest Sale
- Lowest Sale
- Total Transactions
- Best Selling Product
- Currency formatting
- Professional table design

## Excel Skills Used

- SUM
- MAX
- MIN
- COUNTA
- Basic formulas
- Table formatting
- Cell formatting
- Business reporting
- Data organization

## Files Included

- Monthly-Sales-Report.xlsx
- Screenshot of the completed report

## What I Learned

Through this project, I practiced creating a professional business report using Excel. I improved my understanding of formulas, report formatting, summary calculations, and presenting business data in a way that is easy to read and analyze.
