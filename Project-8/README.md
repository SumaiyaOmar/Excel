# Customer Feedback Analysis in Excel

## Project Overview

This project focuses on analyzing a simulated customer feedback dataset using Microsoft Excel.

The dataset contains 40 customer feedback records for different products. The goal was to clean and organize the data, identify customer sentiment and feedback themes, calculate key metrics, and summarize the results using Excel's analysis tools.

## Objectives

- Clean and organize customer feedback data
- Standardize customer names and data formatting
- Identify positive, neutral, and negative feedback
- Identify common feedback themes using keywords
- Calculate customer feedback statistics
- Compare average ratings across products
- Summarize results using PivotTables
- Apply conditional formatting for easier interpretation

## Dataset

The project uses a simulated dataset containing 40 customer feedback records.

The data includes:

- Feedback ID
- Customer Name
- Product
- Rating
- Feedback Date
- Customer Feedback
- Response Status

## Analysis

The analysis includes:

- Total number of feedback records
- Average customer rating
- Positive, neutral, and negative feedback counts
- Average rating by product
- Feedback themes based on keywords
- Product-level feedback comparison
- PivotTable summaries

## Key Learning Outcomes

This project helped strengthen my Excel skills by combining previously learned data cleaning, formatting, formulas, PivotTables, and conditional formatting with new functions such as SEARCH, ISNUMBER, and AVERAGEIF.

It also provided practice in turning raw customer feedback data into a structured and understandable analysis.

## Note

This is a practice portfolio project created using simulated data for learning and demonstration purposes. It does not contain real client or customer information.
