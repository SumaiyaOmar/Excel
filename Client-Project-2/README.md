# 💰 Client Project #2 – Monthly Expense Tracker & Budget Report

## Project Overview

This project was completed as part of my Excel Freelancer Bootcamp, where I build practical business solutions by simulating real client requests.

### Client Scenario

A small café owner needed an Excel spreadsheet to organize monthly business expenses, compare planned budgets with actual spending, and quickly identify areas where expenses exceeded the budget.

## Objectives

- Track monthly business expenses
- Compare Budget vs Actual spending
- Calculate spending differences
- Identify expenses that exceeded the budget
- Create a clear business summary

## Features

- Professional expense tracking table
- Budget vs Actual comparison
- Difference calculation
- Automatic Budget Status using the IF function
- Conditional Formatting to highlight overspending and savings
- Business summary dashboard
- Currency formatting
- Professional report layout

## Excel Skills Used

- SUM
- IF
- Basic arithmetic formulas
- Table formatting
- Conditional Formatting
- Currency formatting
- Data organization
- Business reporting

## Files Included

- Monthly-Expense-Tracker.xlsx
- Screenshot of the completed report

## What I Learned

This project helped me practice creating a real-world business expense tracker in Microsoft Excel. I learned how to compare planned budgets with actual expenses, use logical formulas to categorize spending, apply conditional formatting for better visualization, and build a professional summary section for quick business insights.
