# Sales Tracker and Monthly Report

This Excel project was created to track product sales, calculate revenue, and generate simple business insights using Excel.

## Project Overview
The spreadsheet simulates a small business sales tracking system. It includes sales calculations, summary reporting, sorting, filtering, and spreadsheet formatting.

## Tasks Completed
- Created a structured sales dataset
- Calculated total sales using formulas
- Calculated total revenue
- Identified highest sales values
- Counted total transactions
- Organized and formatted the spreadsheet
- Used sorting and filtering tools
- Applied conditional formatting
- Created a simple business summary report

## Tools Used
- Microsoft Excel
